# TSETMC Recorder — نسخهٔ دوم

اکستنشن محلی Chrome برای ثبت مستقل فیلترهای دیده‌بان، عکس استاتیک با ترتیب الفبای فارسی، ضبط داینامیک و خروجی XLSX/JSON. کد نسخهٔ دوم در شاخهٔ `version-2` قرار دارد.

[دریافت ZIP شاخهٔ نسخهٔ دوم](https://github.com/prestigegitserp/TSETMC_Recorder/archive/refs/heads/version-2.zip)

## نصب جدید

1. ZIP را باز کن.
2. در `chrome://extensions` گزینهٔ Developer mode را روشن کن.
3. Load unpacked را بزن و **پوشهٔ `extension`** را انتخاب کن.
4. آیکون افزونه را بزن، نام فیلترها را وارد کن، پیش‌نمایش را بررسی کن و ضبط را شروع کن.

برای استفادهٔ معمول به Node.js، Python یا نصب بسته احتیاج نیست. اگر جدول پیدا نشد، «انتخاب F8» را بزن و خانهٔ نماد را مشخص کن. «عکس + Excel» همان عکس را ذخیره و فایل XLSX آن را می‌سازد.

## به‌روزرسانی نسخهٔ اول و حفظ داده‌ها

**افزونهٔ قبلی را حذف نکن.** فایل‌های پوشهٔ `extension` این نسخه را روی **همان پوشهٔ نصب قبلی** جایگزین کن و روی Reload کارت افزونه بزن. نام پایگاه دادهٔ قبلی حفظ شده است؛ سابقه و قالب‌ها با همان شناسهٔ نصب قابل دسترسی می‌مانند. سپس میز ضبط را دوباره باز کن و تب‌ها را به قالب‌های ذخیره‌شده وصل کن.

Load unpacked از یک مسیر جدید معمولاً شناسهٔ نصب دیگری می‌سازد؛ دادهٔ نصب قبلی خودکار به آن منتقل نمی‌شود. برای انتقال بین نصب‌ها، از آرشیو JSON استفاده کن. Reload خود افزونه با رفرش صفحهٔ TSETMC فرق دارد؛ برای فعال‌کردن کد جدید، افزونه تلاش می‌کند اسکریپت را بدون رفرش سایت به تب وارد کند.

## اصلاحات مهم

- تشخیص فرستنده بر اساس شناسه و URL معتبر خود افزونه انجام می‌شود. وجود `sender.tab` دیگر باعث رد شدن پنل داخلی نمی‌شود. صفحهٔ سایت همچنان مجاز به اجرای فرمان‌های مدیریتی نیست.
- نمونه‌برداری، ذخیرهٔ پایدار و انتقال، صف‌های جدا دارند. کندیِ دریافت ACK نمونه‌برداری را بی‌خبر قفل نمی‌کند. سقف صف و بازهٔ ازدست‌رفته آشکار ثبت می‌شوند.
- توقف ضبط، ابتدا نمونهٔ نهایی را وارد صف پایدار می‌کند؛ شروع دوبارهٔ هم‌زمان و دو بار کلیک روی شروع کنترل می‌شوند.
- جدول مجازی حتی با گزینهٔ «پوشش تأییدشده» کامل فرض نمی‌شود. لینک واقعی نماد نسبت به `id` عددیِ تصادفی سطر اولویت دارد و عناوین چندسطحی جدول خوانده می‌شوند.
- آمار حضور با بازهٔ زمانی خروجی هماهنگ است. اولین فریم بازه، در صورت نیاز به شکل `range_keyframe` کامل بازسازی می‌شود.
- آرشیو از یک تراکنش خواندن مشترک گرفته می‌شود؛ شمارندهٔ نشست و فریم‌ها از دو لحظهٔ متفاوت مخلوط نمی‌شوند.
- نام فایل فارسی با محدودیت **بایت** کنترل می‌شود. رفرش هنگام وجود دادهٔ ذخیره‌نشده/در صف متوقف می‌شود.

## آزمون

```sh
npm install
npm test
npx playwright install --with-deps chromium
npm run test:browser
```

آزمون مرورگر یک پروفایل موقت Chromium می‌سازد و پاسخ‌های TSETMC را با **فایل ساختگی محلی** جایگزین می‌کند. فرستندهٔ واقعی Chrome، IndexedDB، چند تب، رفرش، توقف، سند offscreen و بارگیری XLSX را می‌سنجد. این آزمون تأیید اتصال به سایت زندهٔ TSETMC نیست. وضعیت آخرین اجرای خودکار را در بخش Actions همین مخزن ببین.

خروجی معمول در `Downloads/BORSA` است. سقف فعلی هر XLSX، ۲۰۰ هزار ردیف داده و هر برگه ۵۰ هزار ردیف است؛ عبور با خطای آشکار متوقف می‌شود و دادهٔ ذخیره‌شده حذف نمی‌شود. برای حجم بیشتر نشست/بازه را کوچک‌تر کن یا JSON بگیر. حافظهٔ داخلی فیلتر دلخواه، بدون قرارداد صریح، قابل بازیابی تضمینی نیست؛ رفرش خودکار پیش‌فرض خاموش است.
